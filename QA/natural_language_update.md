# 2026-11-01 自然语言中枢更新

主入口改为 DeepSeek 多轮工具调用，旧任务类型选择和沙盒关键词预览不再呈现在主要自然语言流程。网页与 UE 原生输入共用执行器。使用 deepseek-flash，明确关闭 thinking。

模型可查询园区实时状态和实体清单，按自然名称、保存别名、坐标方位、地图选择及对话历史定位，组合现有控制能力。支持灯光、电器批量供电、员工调度/通知、门禁、巡检、无人机、实物物流、火情、全园节电、设施、空调、会议及访客登记业务。批量灯区和电器操作通过 UE 控制器执行，并逐端点核对遥测。员工通知增加独立收件回执，避免短消息列表滚动导致确认丢失。

自然语言不是任意脚本执行器：现场未实现的路线、物品或物理能力仍不编造。身份权限、真实实体存在性和物理联锁继续在本地校验；模型不读取 API 密钥或登录凭据。模型不可用时明确失败，不使用关键词规则代替。局部目标不能悄悄扩展为全园动作。每轮分别保存模型处理状态与实体动作状态，网络重试复用幂等请求，不重复执行。
